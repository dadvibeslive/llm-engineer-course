# LLM Engineer Self-Learning Course

A self-learning course to become a production-ready LLM engineer — capable of building, fine-tuning, evaluating, optimizing, and deploying large language models.

- **21 phases, 242 topics**, organised into 5 tracks
- Each phase: outcome, hands-on build project, engineer's note, and curated resources
- **84 learning links** — free, beginner-friendly picks, all clickable, opening in a new tab
- Interactive pace picker (5 / 10 / 20 hrs per week), live search, track filters, graduation checklist

## Live site

https://llm-engineer-course.pages.dev/

## Files

- `index.html` — the full course, single self-contained page (exported from the Muse artifact `llm-engineer-self-learning-course`)

## How to update

Edit the course in Muse, re-export the artifact, replace `index.html` here, commit, and redeploy to Cloudflare Pages.
